================================================================================
                              6 MCP TOOLS
================================================================================

1. get_pull_request
   - Fetch complete PR information
   - Returns: title, description, author, state, labels, stats, reviewers

2. list_changed_files
   - List all modified files
   - Returns: filename, status, additions, deletions, patch snippets

3. get_diff
   - Get complete unified diff
   - Returns: diff text, file count, addition/deletion stats

4. suggest_review_comments
   - AI-powered review suggestions
   - Detects: risky files, large changes, missing tests, code smells
   - Returns: structured suggestions with risk score (0-100)

5. post_review_comment
   - Post comments to GitHub PRs
   - Supports: general and line-specific comments
   - Returns: comment ID, URL, timestamp

6. generate_release_notes
   - Create formatted release notes
   - Categorizes: features, fixes, refactors, docs, breaking changes
   - Returns: markdown with contributor list

================================================================================
                          QUICK START GUIDE
================================================================================

1. SETUP
   python -m venv .venv
   .venv\Scripts\activate
   pip install -r requirements.txt
   cp .env.example .env
   # Edit .env and add your GitHub token

2. VERIFY
   pytest -v
   # All 39 tests should pass

3. RUN
   python main.py

4. INTEGRATE
   Add to Claude Desktop or Cline configuration:
   {
     "mcpServers": {
       "repo-assistant": {
         "command": "python",
         "args": ["/path/to/repo-assistant-mcp/main.py"],
         "env": {"GITHUB_TOKEN": "your_token_here"}
       }
     }
   }
